# 異世界転生シミュレーター

`index.html`をブラウザで開くだけで遊べます。スマートフォンへ配信する場合も、このフォルダーを静的ホスティングに配置するだけです。インストール・ビルド・APIキー・外部フォントは不要です。

## LIFE EDITION 2.0

最初の転生演出で、種族→王国→家族→誕生を順に開示。6王国に医療・教育・情勢・平均寿命・国技・風習・所得・物価を設定し、親の仕事・性格・健康・不在やきょうだい、家の予算と支え合いも抽選します。金額と平均寿命は架空の設定値です。

人生は各年代3件、計18件の日々の出来事が自動で流れ、6回の重要な3択で停止します。一時停止、3段階の速度変更、手動で一件進める操作を用意。非表示のタブでは進行を止めます。現代との比較は画面右上で非表示にできます。

王国の医療は健康・寿命・危険な挑戦の死亡率、教育は知力の伸び、情勢と家庭事情は家計や出来事に影響します。親や故郷の設定は年表と結末へ引き継がれます。毎回外部AIで生成するのではなく、整合した設定と文章をローカルで組み合わせます。

v2は別の保存領域を使い、旧版の保存データは残します。`world.js`が旧エンジンを拡張し、`app-v2.js`と`world.css`が新しい画面を担当します。検証は `node test-v2.cjs`。旧版の検証は `node test.cjs`。

## 基本ルール

「新しい人生に転生する」で4種族・4家柄・4才能と初期能力を抽選。幼少期から晩年まで6回の3択を選びます。36イベントから各年代につき1件を抽選。危険な選択で死亡すると、その時点でエンディングへ進みます。

体力・知力・心力・運が成功率に影響します。健康は失敗時の死亡率に影響します。旅立ちの選択と能力・富から、勇者／冒険者／魔導学者／職人／商人／癒やし手に分岐します。種族ごとに寿命の基準が異なり、富・幸せ・名声と年表から生涯を振り返ります。

成功率と「失敗時」の死亡率は独立した判定です。実際の一選択あたりの死亡率は `(1 - 成功率) × 失敗時死亡率`。安全な選択には死亡判定がありません。総合得点や勝敗はありません。

進行はlocalStorageに保存。ブラウザ設定やローカルファイルの扱いによっては保存できません。その場合もプレイできます。エンディングから年表をテキスト保存できます。リプレイ時に前の進行を上書きします。

## ファイル

- `index.html`：画面構造
- `style.css`：レスポンシブな表示、CSSによる風景画
- `engine.js`：データ、乱数抽選、判定、エンディング
- `app.js`：画面、操作、自動保存、年表出力

進行はブラウザ内の確率ロジックのみで実行します。生成AIとの通信はありません。イベントはMVP向けに3つの判定方針（挑戦・知恵・支え合い）を共通化しています。
